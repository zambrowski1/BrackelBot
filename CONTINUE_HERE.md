# Продолжение BrackelBot на другом ПК

Актуальное состояние на 12 октября 2026 года. Начните с этого файла: старые инструкции и отчёты в `handoff/2026-10-12` отражают прежние версии и не заменяют правила ниже.

## Скачать проект

Нужны Git и Python 3.12 или новее. В PowerShell:

```powershell
git clone https://github.com/zambrowski1/BrackelBot.git
cd BrackelBot
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -c requirements-tested-server.txt '.[server,test]'
.\.venv\Scripts\python.exe -m pip install -r requirements-lua-tests.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -X utf8 handoff/2026-10-12/latest/check_articles.py
```

Если клон уже есть, сохраните свои изменения и выполните `git pull --ff-only`. Для GUI дополнительно установите `.[gui]` по инструкции `docs/WINDOWS_GUI.md`.

## Что уже сделано

Полный цикл Sofascore собирает данные, сравнивает карточку и КлСтат и готовит diff. Режим всех доступных сезонов не ограничивается «Байером»: старые сезоны, отсутствующие в API, сохраняются из прежней таблицы. Есть номер игрока, даты по подтверждённым матчам, итоги клуба и карьеры, примечания к группам турниров.

СбМатчи получает полный подтверждённый список из API. Существующая обычная таблица переносится с проверкой границ, матчей, сносок, ревизии и хешей. Несопоставленная старая встреча не удаляется автоматически. Проанализированы 50 статей; материалы — `docs/FIFTY_ARTICLE_FORMATS.md` и `docs/fifty-article-survey.json`.

У Шика готова таблица основной сборной на 56 матчей / 26 голов. Отдельно по официальному протоколу исправлена ошибочная старая встреча с Данией 15.11.2016; объяснение и источники есть в сохранённом отчёте. У Грифо подтверждены 9 / 4.

У Крамарича новая СбМатчи не создана: общий ответ API — 119 / 36, по отдельным встречам подтверждены 116 / 35. Прежние данные сборных сохранены. У Центнера взрослая сборная не добавляется; молодёжные строки сохраняются.

В четырёх статьях проверены все 19 клубных блоков и исправлены отсутствовавшие флаги. Для неизвестных справочнику клубов используются проверяемые сведения Wikidata; резервные команды распознаются через подклассы футбольных команд. Неоднозначные флаги остаются в отчёте.

## Действующие правила пользователя

1. Для клубной статистики брать доступные сезонные показатели Sofascore без обязательного пересчёта каждого матча. Проверки личности, клуба, турнира и разделения статистики при переходах сохраняются.
2. Недоступные новые показатели выводить как **0**, не тире и не вопросительные знаки. В исходных данных пропуски остаются `null`; показанные нули не доказывают отсутствие матчей. Итоги складывают показанные строки.
3. В карточке — матчи чемпионата. У вратарей пропущенные голы записываются отрицательными числами. Нулевые голы в СбМатчи показываются цифрой **0**.
4. Общий источник обеих таблиц — `<ref>{{Cite web|…}}</ref>` на профиль игрока Sofascore внутри второго параметра `Обновлено`. Ссылки API на отдельные матчи остаются в пакете проверки, а не в каждой строке таблицы. Редакторские сноски сохраняются.
5. Дата актуальности берётся из последнего подтверждённого матча, дата обращения к источнику хранится отдельно. Поле даты сборной в карточке добавляется, если отсутствует; молодёжные строки не блокируют дату основной сборной. У Шика — 25.06.2026, у Грифо — 26.03.2023.
6. Период основной сборной по умолчанию — `начальный год—{{н. в.}}`. Явный конечный год сохраняется, пока не подтверждены дополнительные выступления либо матч после конечного года. Исправление одних голов не открывает период. Последний сыгранный год сам по себе не означает завершения карьеры.
7. Флаг определяется по подтверждённой стране клуба. В КлСтат порядок: **флаг → стрелка аренды/фарм-клуба → название**. Подписи ссылок и сноски сохраняются.
8. Публикации в Википедии в этих проверках не было: готовые статьи передавались пользователю файлами для ручного переноса.

## Ссылки на сезоны: подключено к полному циклу

Уточнённая задача — искать сезоны всех футбольных лиг, включая низшие дивизионы, с 2010 года. Общий каталог `wiki_stats/season_catalogue.json` подключён к поиску до прежних вариантов названий. Добавлены 341 подтверждённое перенаправление на названия лиг; неоднозначные сочетания лиги и сезона не выбираются произвольно. Общие объекты вроде «Чемпионат России» не заменяют конкретную лигу.

Обход найденных корневых категорий завершён, результат воспроизводится без сети. Это не доказательство нахождения каждой статьи Википедии: страницы без подходящих категорий и связей Wikidata могут остаться вне каталога. Пустая строка `coverage.csv` не доказывает отсутствие статьи. Проверка:

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/check_season_catalogue.py
```

Источники и порядок обновления каталога: `docs/SEASON_CATALOGUE.md`. Все команды этого этапа читали только Wikimedia; запросов к футбольному провайдеру и записей в Википедию — **0**.

Пользователь уточнил диапазон: **с 2010 года до текущего сезона**, не более ранние сезоны. В КлСтат показывать полные годы, например:

```wikitext
[[Чемпионат Германии по футболу 2026/2027|2026/2027]]
```

Код `wiki_stats/season_links.py` и операция `normalize_season_links` подключены к `prepare-player` после статистики и флагов. Сноски, комментарии и отметки аренды внутри и снаружи подписи сохранены. Проверены повторное применение и защита от смены лиги. Старый `season-links-pipeline-draft.txt` теперь только исторический набросок.

Последние четыре статьи и `four-articles.zip` обновлены: 61 сезонная ячейка получила проверенные ссылки с полными годами. У Центнера для трёх сезонов подходящие статьи по проверенным названиям не найдены: региональная лига 2012/13 и 2013/14, третья лига 2016/17. Их прежний текст сохранён; новые ссылки не придуманы.

Проверить статьи и повторяемость без сетевых запросов:

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/refresh_draft_season_links.py --check
.\.venv\Scripts\python.exe -X utf8 handoff/2026-10-12/latest/check_articles.py
```

Подробности и границы проверки: `docs/SEASON_LINKS.md`. Для новых лиг названия по-прежнему нужно подтверждать; отсутствие статьи не является ошибкой статистики. Новых запросов к футбольному провайдеру при этом обновлении: 0. Записи в Википедию: 0.

Существование статьи и соответствие сезону/лиге нужно подтверждать. Если статья не найдена, не придумывать ссылку.

## Секреты и сервер

API-ключи, пароли, SSH-ключи и виртуальные окружения не включены. API-секреты находятся в защищённой конфигурации Toolforge. Перед новыми обращениями проверить текущую квоту; прежний остаток не считать актуальным.

На другом ПК для SSH потребуется свой ключ и доступ пользователя `zambrowski` к инструменту `brackelbot`. Перед развёртыванием проверить состояние сервера. В прошлой проверке production содержал старые локальные изменения; последние прогоны выполнялись из отдельной копии кода. Не перезаписывать эту рабочую копию и конфигурацию без разбора различий. `git push` не разворачивает код на Toolforge.
