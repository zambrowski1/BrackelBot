# Разработка

Для серверной части нужны Python 3.12+ и pytest. Из корня проекта:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -c requirements-tested-server.txt -e '.[server,test]'
.venv/bin/python -m pytest -q
```

В Windows путь к Python — `.venv/Scripts/python.exe`.
Серверные тесты используют локальные снимки и имитацию API. Ключи и аккаунты
не нужны. Чтобы запустить тесты GUI, дополнительно установите `.[gui]`.

Серверные тесты автоматически запускаются на GitHub для Python 3.12, 3.13 и 3.14.
В тестах запрещены живые HTTP-запросы через requests: используйте снимки и
имитацию ответов. Проверки серверного цикла находятся в `tests/test_server.py`,
сбора API — в `tests/test_api_football.py`, составов и переходов — в
`tests/test_source_validation.py`.

Для исправления ошибки добавьте пример, на котором она воспроизводится.
В PR укажите, что изменилось и как это проверили. Если меняется публикация,
проверьте конфликт ревизий, подтверждение операций и аварийную остановку.

Не добавляйте ключи, пароли, рабочие базы и API-кэш. У новых зависимостей
проверьте лицензию и обновите [список библиотек](docs/THIRD_PARTY_LICENSES.md).
Код проекта распространяется по MIT. Для чужих текстов и данных сохраняйте
их лицензию и атрибуцию.
