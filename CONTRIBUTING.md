# Разработка BrackelBot

Python 3.12+. Серверные тесты не требуют Qt, аккаунтов или API-ключей:

```bash
python -m venv .venv
# Linux: .venv/bin/python; Windows: .venv/Scripts/python.exe
.venv/bin/python -m pip install -e '.[server,test]'
.venv/bin/python -m pytest -q
```

Тесты GUI включаются установкой extra `gui`; используйте интерактивную Windows
сессию либо поддерживаемую Qt среду. Работа на настоящем Toolforge проверяется
отдельно по docs/TOOLFORGE.md. Не отправляйте реальные правки из тестов.

Новые зависимости добавляйте в pyproject.toml, проверяйте их лицензии и
обновляйте docs/THIRD_PARTY_LICENSES.md. Сохраняйте notices библиотек и атрибуцию
фикстур. Код вкладов лицензируется MIT; материалы с другими лицензиями
добавляются с отдельной атрибуцией. Не добавляйте API-ключи, BotPasswords,
дампы состояния или реальные ответы API без проверки прав на распространение.

Пишите issue/PR с конкретным примером входных данных без секретов, ожидаемым
поведением и результатами соответствующих тестов. Изменения публикации должны
сохранять whitelist, проверку ревизии, отдельное подтверждение и kill-switch.
