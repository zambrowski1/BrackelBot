# Авторизация BotPasswords

Используется поддерживаемый MediaWiki вход `action=login` с паролем бота,
HTTPS, cookies в памяти и CSRF-токеном для сохранения. OAuth не реализован.

1. Войдите в русскую Википедию в браузере под своей учётной записью.
2. Откройте [Специальная:BotPasswords](https://ru.wikipedia.org/wiki/Специальная:BotPasswords).
3. Создайте отдельный пароль с именем приложения `BrackelBot`. Разрешения:
   базовый доступ и редактирование существующих страниц. Дополнительные
   права загрузки файлов, удаления, защиты, массовых правок не нужны.
4. Сохраните выданный пароль в своём менеджере паролей. В программе нажмите
   «Войти через BotPasswords»: имя вида `Zambrowski@BrackelBot`, выданный
   пароль бота. Основной пароль Википедии вводить не нужно.
5. При успешном входе приложение покажет имя учётной записи. Сессия действует
   только до выхода или закрытия приложения; после перезапуска войдите снова.

Программа не сохраняет пароль, cookies или токены на диск, в JSON обновлений
или в журнал. Пароль кратковременно находится в памяти для HTTPS-запроса.
Журнал содержит имя вошедшего участника, номера ревизий и результаты операций.
Диагностика POST не выводит тело запроса или текст ответа сервера.

Выход очищает cookies и подтверждения. При потере авторизации обработка
останавливается. Пароль бота можно отозвать на странице BotPasswords.

Авторизация не расширяет белый список: код Publisher и API-клиент разрешают
правки только на `Участник:Zambrowski/testbot`. Режим Manual надо выбрать
отдельно. Dry Run и Automatic не отправляют правки.

В этой поставке вход и сохранение проверены автоматическими тестами с
имитацией MediaWiki. Живой вход с вашим паролем и реальное сохранение ещё
предстоит проверить вместе с вами. Разработчик не выполнял реальных публикаций.

Документация: [BotPasswords](https://www.mediawiki.org/wiki/Manual:Bot_passwords),
[API Login](https://www.mediawiki.org/wiki/API:Login),
[API Edit](https://www.mediawiki.org/wiki/API:Edit).
