# Справочник клубов

Состав сезона **2026/27**, проверен 9 октября 2026 года: 18 команд Бундеслиги,
18 команд второй Бундеслиги и 20 команд третьей лиги. У всех 56 команд есть
отдельные русские статьи. Дубли Штутгарта и Хоффенхайма имеют собственные QID.
Дополнительно сохранены Рома, Спортинг и историческая запись Мюнхена 1860.

В `wiki_stats/clubs.json` хранятся статья, QID, подпись ссылки, варианты русского,
немецкого и английского названия, сезон и уровень лиги. Например, цель ссылки
«Боруссия (футбольный клуб, Мёнхенгладбах)» и видимый текст «Боруссия
(Мёнхенгладбах)» — разные поля. Уже существующую подпись карточки менять не нужно.

Источники состава: [Бундеслига](https://www.bundesliga.com/de/bundesliga/clubs),
[вторая Бундеслига](https://www.bundesliga.com/de/2bundesliga/clubs),
[третья лига, DFB](https://www.dfb.de/news/teilnehmerfeld-der-3-liga-steht-fest-havelse-rueckt-fuer-1860-nach).
Идентификаторы, названия и языковые ссылки: Wikimedia API и Wikidata (CC0).
Таблица — снимок состава конкретного сезона; рабочий состав бот получает из API.

## Использование

Справочник входит в пакет программы и читается автоматически. Посмотреть
его без API-ключа и подключения к базе:

```bash
python -m wiki_stats.server_cli club-list --tier 1
python -m wiki_stats.server_cli club-list --tier 2
python -m wiki_stats.server_cli club-list --tier 3
```

Это справочник названий и ссылок. API ID поставщика по-прежнему нужно связать
с QID через club-confirm; совпадение названий не создаёт такую связь автоматически.
Основная команда и дубль не взаимозаменяемы. Для добавления дубля редактор
требует явный role=reserve.

## Если русской статьи нет

Для новой записи задайте русское name, предполагаемое title, display_name,
QID, aliases, страну и флаг. Для отображения в автономном club-list можно также
указать foreign_language и foreign_title. Перед использованием бот сам читает
живые языковые ссылки Wikidata и проверяет QID иностранной статьи. Приоритет —
немецкая Википедия, затем английская. Если русское название уже занято другой
статьёй, или QID не совпал, ссылка не создаётся.

Формат ссылки:

```wikitext
{{нп5|Будущая русская статья|Русская подпись|de|Название немецкой статьи}}
```

Нп5 — перенаправление на «Не переведено».
[Параметры шаблона](https://ru.wikipedia.org/wiki/Шаблон:Не_переведено).
При появлении русской статьи новая проверка предпочитает обычную русскую ссылку;
изменившееся название статьи требует обновления записи справочника. Существующие
строки с нп5 распознаются с проверкой иностранной статьи; аренда и резервные
маркеры по-прежнему требуют отдельного рассмотрения.

## Повторная проверка

```bash
python scripts/verify_club_catalogue.py --report catalogue-verification.json
```

Скрипт проверяет статьи, обратные связи Wikidata, флаги и ссылки. API-Football
и права на редактирование не нужны. Состав сезона и подписи он не переписывает;
ошибки сохраняются в отчёт. Новый сезон добавляется после проверки его состава.
