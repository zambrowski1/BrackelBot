# Данные внешних API

MIT распространяется на код бота. У статистики из внешнего источника могут
быть другие условия использования.

## Highlightly

[Условия Highlightly, §6.1](https://highlightly.net/terms/) разрешают хранение,
передачу и распространение данных в приложениях. Это не открытая лицензия на
всю базу: остаются ограничения на конкурирующие базы и перепродажу доступа к API.
Изображения и логотипы бот не переносит. Ключи разных подписок могут иметь
разные независимые квоты, но использовать их для обхода лимита запрещено (§7).
Настройка и границы интеграции — [HIGHLIGHTLY.md](HIGHLIGHTLY.md).

## API-Football

В [условиях API-Football](https://www.api-football.com/terms) указано, что сервис
не предоставляет лицензию на публикацию всех данных и что могут действовать
права третьих лиц. Допустимость нашего сценария пока не подтверждена.
Это нужно уточнить у поставщика: бот переносит отдельные числовые показатели
в Википедию и хранит внутренний кэш ответов.

Toolforge требует открытый код и открытые данные.
При использовании стороннего API нужно также уточнить, как его ограничения
сочетаются с [Right to fork](https://wikitech.wikimedia.org/wiki/Help:Toolforge/Right_to_fork_policy).
Ответы поставщика и WMCS стоит сохранить здесь перед рабочим запуском.

В репозитории находятся синтетические API-примеры и снимки Википедии
с [атрибуцией](../NOTICE.md). Реальные ответы API и рабочая база в Git не добавляются.

## Копия инструмента

Новая установка начинает с пустой базы (`init-db`). Соответствия игроков,
клубов и исходную статистику подтверждают заново по [руководству оператора](SERVER_OPERATOR.md).
У нового оператора должны быть свои аккаунты и API-ключ.

Для переноса состояния собственного инструмента:

```bash
./brackelbot/toolforge/operator.sh export players ../reports/players.json
./brackelbot/toolforge/operator.sh export clubs ../reports/clubs.json
./brackelbot/toolforge/operator.sh export anchors ../reports/anchors.json
```

Экспорт сохраняет JSON локально. Перед передачей этих файлов другим людям
нужно проверить их состав и права на распространение данных.
