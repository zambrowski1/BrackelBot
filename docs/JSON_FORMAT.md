# Подготовка JSON

JSON 1.0 поддерживает изменение числовой статистики (`update_stats`).
Для трансферов, новых сезонов и других структурных операций используйте
[JSON 1.1](JSON_OPERATIONS.md). Поле `extension_data` в версии 1.0 хранит
предложение, но не выполняет его.

Каждый пакет содержит `schema_version`, уникальный `package_id`,
`generated_at` в RFC 3339 с часовым поясом и массив `articles`.
Для статьи обязательны точный `title`, точное имя `player` из карточки и
`operations`; опциональны `base_revid` и `wikidata_id`.
Указание `base_revid` блокирует анализ при изменении статьи. Если он не указан,
ожидаемые числа проверяются по полученной текущей ревизии, а её номер
сохраняется в отчёте. Перед публикацией ревизия проверяется повторно.

Операция:

| Поле | Значение |
|---|---|
| id | Уникально среди всех операций пакета |
| type | Для исполнения сейчас только `update_stats` |
| entity.name | Читаемое название команды |
| entity.wikitext | Точный викитекст параметра команды/клуба, включая флаги и ссылки |
| entity.wikidata_id | Необязательный Q-ID; не используется для сопоставления |
| season | Точный параметр сезона, включая пометку аренды; для карточки `null` |
| competition.name | Соревнование или совокупность данных источника |
| competition.category | Точный заголовок категории КлСтат; для карточки `all` |
| competition.scope | Для таблицы `category`, клубной карьеры `league`, сборной `national_all` |
| competition.mapping_rule | Обязательно, если name отличается от category в таблице |
| target.structure | `club_table` или `career` |
| target.field | Для career: `клубы` или `национальная сборная` |
| target.period | Для career: точный период, например `2024—{{н.в.}}` |
| expected, new | Объекты с одинаковым непустым набором `appearances`, `goals`; неотрицательные целые числа |
| as_of | Заявленная автором дата проверенного охвата YYYY-MM-DD |
| sources | Непустой массив: url, provenance=`user_provided`, coverage_as_of; необязательный note |

Если меняются только голы, включайте только `goals` в expected и new.
Если требуется проверить и неизменные матчи, включайте оба показателя.
`null` в expected разрешён схемой только для зарезервированных будущих типов.

`competition.mapping_rule` — явное предоставленное человеком правило, а не
автоматически доказанный факт. Если Лига Европы сопоставляется «Еврокубкам»,
new должен содержать **полный итог категории**, а не прибавку или только часть
турниров. В JSON 1.0 программа не объединяет статистику разных турниров.
Кубок лиги нельзя включать в национальный кубок без явного правила.
Для карточки клубная статистика трактуется как матчи чемпионата за указанный
период; статистика сборной — все матчи именно указанной возрастной команды.
Для иных семантик нужен отдельный обработчик, не изменение метки scope.

Все sources.coverage_as_of должны совпадать с as_of. Несовпадение даёт
`source_coverage_mismatch`. Источники с одинаковой датой всё равно могут
противоречить друг другу: программу нельзя считать системой исследования.
Если источники дают несовместимые числа, не создавайте операцию
до выяснения различий. Новые значения не должны быть выбраны наугад.

Дата as_of не изменяет викитекст. Даже корректный пакет не вызывает установку
текущей даты: `update_date` в JSON 1.0 возвращает `operation_not_implemented`.
Эта операция описана в [JSON 1.1](JSON_OPERATIONS.md).
URL не превращает источник в независимо проверенный. Не задавайте
`independently_verified`: входная схема не допускает такого заявления.

Пример минимального фрагмента (новые числа здесь **вымышленные**):

```json
{
  "id": "national-demo",
  "type": "update_stats",
  "entity": {
    "name": "Германия (основная сборная)",
    "wikitext": "{{Флаг Германии|20px}} [[Сборная Германии по футболу|Германия]]"
  },
  "season": null,
  "competition": {"name": "Все матчи основной сборной", "category": "all", "scope": "national_all"},
  "target": {"structure": "career", "field": "национальная сборная", "period": "2024—{{н.в.}}"},
  "expected": {"appearances": 6, "goals": 4},
  "new": {"appearances": 7, "goals": 5},
  "as_of": "2026-10-05",
  "sources": [{
    "url": "https://www.bundesliga.com/de/spieler/tim-kleindienst",
    "provenance": "user_provided",
    "coverage_as_of": "2026-10-05",
    "note": "Синтетический пример, числа источником не подтверждены"
  }]
}
```

Полные пакеты находятся в `examples/`. Для своего пакета возьмите селекторы
из актуального викитекста и проверьте новые числа по источнику.
