# Ограничения

Автоматический цикл обновляет подтверждённую клубную статистику текущего
периода и существующую строку сезона в таблице `КлСтат`. Карьерный итог
считается по исходной базе и изменению сезонной статистики.

Несколько случаев пока требуют ручной подготовки JSON или проверки:

- Первое сопоставление API ID игрока/клуба с QID и статьёй. Поиск по имени
  предлагает кандидатов; совпадение подтверждает оператор.
- Начальная карьерная база. Нужны карьерные и сезонные числа на одну дату.
- Кубки, еврокубки и сборные: их статистика не выводится из данных чемпионата.
- Трансферы, аренда, резервные команды и возвращение в прежний клуб.
- Новый сезон, если значения остальных категорий неизвестны.
- Произвольные `wikitable`, неизвестные шаблоны и сложные `rowspan`/`colspan`.
- Дата последнего матча: дата получения ответа API не используется вместо неё.

Неизвестное значение не заменяется нулём. Если формат статьи не поддерживается
или исходные числа изменились, бот оставляет предложение для ручной проверки.
Он не создаёт отсутствующие статьи и не удаляет историю карьеры.

Восстановление страницы целиком доступно только для testbot. Для основных
статей требуется отдельная правка с проверкой новой ревизии.

## Что нужно проверить перед запуском

На настоящем Toolforge ещё предстоит проверить установку, Envvars, ToolsDB,
сохранность состояния, блокировку конкурирующих заданий и расписание.
Тесты используют SQLite и имитацию внешних сервисов.

Нужно также проверить доступность сезона по своему тарифу API-Football,
сопоставления игроков, карьерные базы, вход в Википедию и пробную запись
на testbot. Для автоматических правок нужны одобрение ботозадачи и настроенный
список разрешённых статей. [Установка](TOOLFORGE.md), [работа с ботом](SERVER_OPERATOR.md).
