# Перенос таблицы сборной в СбМатчи

Команда переносит существующий список матчей в шаблон. Числа остаются прежними; обновление через API выполняется отдельным шагом.

```powershell
python -m wiki_stats.server_cli prepare-national-table "Шик, Патрик" --player "Патрик Шик" --output-dir reports/schick-national
# Для молодёжной таблицы выбирается возраст:
python -m wiki_stats.server_cli prepare-national-table "Браккельман, Кальвин" --player "Кальвин Браккельман" --age 18 --output-dir reports/brackelmann-u18
```

Результат: `before.wiki`, `after.wiki`, `changes.diff`, `package.json` и `report.json`. Команда ничего не публикует и не расходует футбольную квоту. Проверка без сети принимает `--fixtures` с сохранённой ревизией статьи.

Сборная и возраст сверяются с карточкой. Поддержаны обычные и именные заголовки, `|+`, подсказки `comment`/`abbr`, разные названия столбцов для вратаря. Дополнительные столбцы места проведения, передач, минут и примечаний переносятся в соответствующие параметры. Пометка дополнительного времени сохраняется в примечании, включая её ссылку. Серия пенальти хранится отдельно от счёта матча.

Источники заголовка, строк и проверенного итога остаются в шаблоне. Отдельный старый итог можно убрать только после совпадения с суммой строк. Годовые сводки и таблицы других возрастов сохраняются. Даты словами и через `{{date}}` становятся числовыми параметрами; шаблон выводит их словами. Если старые строки расположены не по датам, их порядок сохраняется через `порядок=исходный`.

Каждая замена привязана к ревизии, исходному участку текста и списку матчей. При изменении статьи готовится новый пакет. Повторное применение не создаёт вторую таблицу. Неизвестная разметка, объединённые ячейки, минуты голов через `{{гол}}`, непроверенные итоги и неоднозначная сборная останавливают перенос. Подробности проверки 50 статей: [отчёт](FIFTY_ARTICLE_FORMATS.md).

После переноса обычный `prepare-player` собирает данные Sofascore и готовит `reconcile_sbmatches`, если подтвердился полный список основной сборной. Старые строки сопоставляются по дате и сборной соперника. Все прежние матчи должны быть найдены; непарная строка означает конфликт, а не разрешение её удалить. Ссылки и примечания редакторов сохраняются, новые матчи получают ссылки на протоколы Sofascore. Итоги пересчитывает шаблон. Дата определяется по последнему подтверждённому матчу и не уменьшается.

В проверке Шика 12 октября API дал 56 матчей и 26 голов. В старой таблице есть Дания — 15 ноября 2016 года, которую полученный список выступлений не содержит. Обновление списка остановлено с `national_existing_match_unmatched`; статья не изменена. Это расхождение требует проверки источника, а не снятия защиты от удаления.
