# Перенос таблицы сборной в СбМатчи

Эта команда меняет формат старой таблицы. Она не добавляет матчи из API, не исправляет голы и не обновляет дату статистики или карточку футболиста.

Например, для Шика:

```powershell
python -m wiki_stats.server_cli prepare-national-table "Шик, Патрик" --player "Патрик Шик" --output-dir reports/schick-national
```

В папке результата появятся исходный текст `before.wiki`, исправленный `after.wiki`, разница `changes.diff`, пакет правок `package.json` и отчёт `report.json`. Команда ничего не публикует и не расходует футбольную квоту. Для проверки без сети можно передать `--fixtures` с сохранённой ревизией статьи.

Пока поддерживается одна обычная таблица с шестью столбцами: номер, дата, соперник (или оппонент), счёт, голы (или пропущенные голы), соревнование. Сборная и возраст сверяются с карточкой футболиста. Соперники, ссылки на соревнования и сноски сохраняются. Даты словами и через `{{date}}` переводятся в числовую запись; на странице СбМатчи снова показывает их словами. Прочерки в старых числовых ячейках читаются как ноль.

Бот заменяет только участок самой таблицы. Окружающий текст, дата обновления и другие таблицы остаются на месте. Пакет привязан к ревизии статьи, контрольным суммам старой таблицы и нового шаблона, а также списку матчей. При изменении статьи пакет нужно подготовить заново. Повторное применение того же переноса ничего не добавляет.

Если есть несколько таблиц сборной, неизвестный блок статистики, комментарии внутри таблицы, объединённые ячейки, дополнительные столбцы, именной заголовок или отдельная строка итогов под таблицей, автоматического переноса не будет. Эти случаи сначала нужно разобрать вручную. Обычная операция создания СбМатчи по-прежнему отказывается добавлять шаблон рядом с возможной старой статистикой.

У Шика старая таблица содержит 50 матчей и 24 гола, а карточка — 56 матчей и 26 голов. Перенос сохраняет эти исходные данные. Он не выдаёт старый список за обновлённую статистику: добавление недостающих встреч — следующий отдельный шаг.
