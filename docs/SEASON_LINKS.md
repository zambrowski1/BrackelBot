# Ссылки на сезоны в КлСтат

Полный цикл `prepare-player` вызывает `season_links.prepare` после обновления чисел и нормализации флагов. Обрабатываются сезоны с начальным годом 2010 до года запуска включительно. Например, `2026/27` становится `[[Чемпионат Германии по футболу 2026/2027|2026/2027]]`.

Название статьи проверяется через Action API русской Википедии. Перенаправление допускается только на один из названий той же лиги и сезона. При наличии Wikidata проверяется обратная ссылка. Не найденные статьи и неизвестное оформление записываются в отчёт; новая ссылка не создаётся.

В существующей подписи меняются только годы: отметка аренды, комментарий и сноска сохраняются. Числа матчей/голов, заголовки клубов и сборные не меняются. Применение операции проверяет игрока, исходную ячейку и её лигу, требует привязки к ревизии и повторной проверки статьи сезона. Повторное применение не создаёт новых изменений.

Для последних четырёх черновиков сохранён ответ Википедии на 68 названий-кандидатов, полученный за 7 коротких пакетных чтений. Футбольный API не использовался. Обновлено 61 сезонная ячейка: Грифо — 15, Крамарич — 21, Центнер — 12, Шик — 14. Три оставшиеся ячейки Центнера не получили ссылок: региональная лига 2012/13 и 2013/14, третья лига 2016/17. Проверенные варианты названий отсутствуют; прежний текст сохранён.

Файлы: `handoff/2026-10-12/latest/season-link-evidence.json`, `season-link-report.json`, отдельные `*seasons.diff` и обновлённый `four-articles.zip`.

Проверить подготовленные статьи без сети и перезаписи результатов:

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/refresh_draft_season_links.py --check
.\.venv\Scripts\python.exe -X utf8 handoff/2026-10-12/latest/check_articles.py
```

`--refresh-evidence` читает только Википедию и заново проверяет названия. Вспомогательный скрипт не вызывает футбольный API и не публикует изменения. Запуск без `--check` перезаписывает черновики, архив и отчёт текущего прогона; для просмотра используйте `--check`.
