# Матрица обязательных сценариев

Проверки этапа 1 отличают успешную реализацию от безопасного отказа.
Зелёный тест отказа **не означает**, что будущая функция реализована.

| № | Сценарий задания | Проверка / текущая поддержка |
|---|---|---|
| 1 | Одно число | `test_single_number`: успешный preview |
| 2 | Матчи и голы | `test_pair_and_remainder_exact`: два адресных патча |
| 3 | Сборная | `test_national_statistics`: карточка, без таблицы матчей |
| 4 | Новый сезон | `test_later_stage_operations_explicitly_disabled`: отказ, вставка не реализована |
| 5 | Новое соревнование в категории | Явное сопоставление при `update_stats` проверено; `add_competition` пока отклонён |
| 6 | Нет колонки | `test_new_category_demands_review`: предупреждение, без перестройки |
| 7 | Обновить итоги | Арифметическая диагностика проверена; `update_totals` не реализован |
| 8 | Некорректный JSON | `test_invalid_input`, BOM, повторные ключи; до API |
| 9 | Нет сезона | `test_missing_season`: отказ |
| 10 | Старое значение не совпало | `test_old_mismatch_is_atomic`: никаких частичных патчей |
| 11 | Неизвестный шаблон | Карьера и таблица отклонены с `unsupported_structure` |
| 12 | Чужое изменение статьи | `test_revision_changed`: отказ при base_revid; конфликт записи ещё не реализован |
| 13 | Повторить JSON | `test_repeated_apply`: already_applied, пустой diff |
| 14 | Остальной текст неизменен | Обратное применение патчей восстанавливает весь исходник; сноски/пробелы/комментарии сохранены |
| 15 | Новый клуб без дат | add_club отклонён независимо от дат; добавление клуба ещё не реализовано |

Дополнительно: три настоящих снимка, основной/резервный клуб, повторные
параметры и строки, перекрывающиеся операции, несовпадение имени футболиста,
охвата источников, отказ от фиктивного independently_verified, GET-only API,
защищённая страница при чтении, ошибки соединения/доступа, ограниченные повторные
запросы, остановка пакета при отказе доступа, отчёт и журнал, запрет публикации
в каждом режиме. Qt проверен через offscreen GUI с реальным QThread.

Результат финального прогона находится в `verification.txt`. Упакованный EXE
и работа на чистых Windows 10/11 отдельно не испытаны.
