# Приложение для Windows

GUI позволяет вводить статистику через форму или загружать JSON-пакеты. Ключ API-Football для него не нужен.
Он показывает старые и новые значения, ошибки проверки и diff страницы.

## Запуск из исходников

Нужны Python 3.12+ и интернет для установки зависимостей. Откройте `START.bat`
в корне проекта: скрипт создаст окружение и запустит приложение.

Вручную из PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[gui]"
.\.venv\Scripts\python.exe run_gui.py
```

Если у вас уже есть Windows-сборка, запускайте её через `START.bat` из папки
с EXE. Папка `_internal` должна оставаться рядом с исполняемым файлом.

## Проверка пакета

1. Нажмите «Загрузить JSON», затем «Проверить статьи».
2. Выберите операцию и откройте «Показать изменения».
3. Сверьте исходные числа, источник и diff. Подтвердите или отклоните операцию.
4. Сохраните отчёт, если нужно передать результаты проверки.

## Ввод без JSON и API

1. Нажмите «Ввести статистику», укажите название статьи и нажмите «Получить из Википедии».
2. Выберите строку клубной карьеры, сборной или категорию конкретного сезона.
   Рядом показаны старые матчи и голы. Их бот берёт из статьи, редактировать их не нужно.
3. Введите новые числа, ссылку на подтверждающий источник и дату охвата его данных
   в формате `ГГГГ-ММ-ДД`. Дата не подставляется автоматически.
4. Для основной статьи подтвердите принадлежность игрока к сфере задачи — Бундеслиге.
5. Нажмите «Подготовить правку», затем просмотрите diff и предупреждения.
   Для сезонной таблицы итоги пересчитываются вместе с изменённой строкой;
   карточка и даты актуальности отдельной правкой автоматически не меняются.
6. Кнопкой «Сохранить пакет» можно сохранить ввод для серверного CLI или повторной проверки.
   Пакет привязан к ревизии статьи: после изменения страницы нужно подготовить его заново.

Форма готовит одну операцию за раз. Сложные переходы и связанные изменения
по-прежнему задаются JSON-пакетом. Источник и числа проверяет оператор: наличие
ссылки не означает независимую проверку статистики ботом.

Для работы без интернета нажмите «Открыть локальный снимок» и выберите, например,
`tests/fixtures/kleindienst.json`. Рядом должен лежать `kleindienst.wiki`.
После подготовки повторная проверка также использует этот снимок, без сети.
Публикация такого предпросмотра отключена. Тестовые новые числа можно придумать,
но они не предназначены для настоящих статей.

Dry Run не отправляет правки. Для ручной публикации выберите Manual и войдите
через [BotPasswords](AUTHORIZATION.md). После смены режима подтверждения нужно
повторить. Все связанные операции группы должны быть подтверждены.
Ошибка в одной из них отменяет всю группу.

GUI разрешает запись только на `Участник:Zambrowski/testbot`.
Для публикации в основных статьях используйте серверный CLI с настроенными
разрешениями; порядок описан в [руководстве оператора](SERVER_OPERATOR.md).

Перед тестовой записью сохраните исходную версию страницы кнопкой
«Сохранить исходную версию». Восстановление также требует просмотра diff
и подтверждения. Готовые сценарии: [SAFE_TESTING.md](SAFE_TESTING.md).

Формат пакетов: [JSON_FORMAT.md](JSON_FORMAT.md), [JSON_OPERATIONS.md](JSON_OPERATIONS.md).
Случаи, требующие ручной обработки: [LIMITATIONS.md](LIMITATIONS.md).
