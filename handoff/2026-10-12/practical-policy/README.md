Допустимое допущение в сборщике: если все сыгранные матчи замыкаются на число выступлений и сумму голов сезонного источника, отсутствующий показатель голов отдельного матча считается нулём. Матчи привязываются к фактическому клубу из протокола, а номера матчей и допущение остаются в отчёте. При расхождении сумм разделение не применяется. Сохранённый пример Грифо — `grifo-automatic-split.json`.

Новые неизвестные категории показываются тире, явные нули и сохранённая старая статистика остаются. Неполные клубные итоги используют обычную строку викитаблицы; карьерный итог не добавляется, если не хватает слагаемых. Предупреждения о неполноте в текст статьи не вставляются.

Три встречи федерации добавляет отдельный инструмент подготовки черновиков, `tools/practical_draft_policy.py`. Сборщик Sofascore автоматически федерацию не опрашивает: аналогичную новую нехватку матчей он по-прежнему вынесет на проверку. Неизвестные старые сезоны и показатели резервных команд остаются ограничением источника.

Воспроизводимые проверки без сети:

```powershell
python -X utf8 tools/practical_draft_policy.py
python -X utf8 tools/recheck_saved_four.py
python -X utf8 tools/refresh_draft_season_links.py --check
python -X utf8 handoff/2026-10-12/latest/check_articles.py
```

`report.json` содержит сверку показателей и оставшиеся пробелы. `draft-replay.json` подтверждает повторный запуск без изменений. `article-manifest.json` содержит хеши готовых текстов, `*-policy.diff` — изменения относительно предыдущей версии. Готовые статьи и модуль находятся в `../latest/four-articles.zip` и `../latest/articles/`.
