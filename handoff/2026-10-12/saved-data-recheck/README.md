# Повторная проверка четырёх черновиков

Сверены сохранённые данные, а не свежие результаты матчей. Новых запросов к футбольному API — 0; записей в Википедию — 0. SHA-256 и размеры всех 139 файлов `latest/latest-evidence.zip` совпали с манифестом.

Проверены 68 сезонных строк: 124 пары «матчи/голы» сопоставлены с сохранёнными ответами API или отдельно проверенным разделением переходного сезона. Все 65 строк СбМатчи Грифо и Шика сопоставлены с проверенными пакетами; даты, голы и счета также сверены с исходными сохранёнными матчами. Проверены арифметика, карточки текущих клубов, даты обновления, сохранение ссылок и даты рождения, порядок разделов, флаги и повторная обработка ссылок на сезоны.

## Исправления

- Грифо, 2018/19: API прикрепил общий итог Бундеслиги 23/7 к «Фрайбургу». Сохранённая история содержит 23 подтверждённых выхода: 16/6 за «Фрайбург», 7/1 за «Хоффенхайм». Их суммы точно замыкаются на общий сезонный показатель. Исправлена строка «Фрайбурга», добавлена строка «Хоффенхайма» с кубком 2/0 и Лигой чемпионов 1/0 из отдельных сезонных ответов, пересчитаны итоги. В карточке «Хоффенхайм» за 2018—2019 исправлен с 8/1 на 7/1. Идентификаторы всех 23 матчей сохранены в `report.json`.
- Крамарич: раздел статистики перенесён перед достижениями; содержание разделов сохранено.
- В сборщик добавлена защита: если сохранённая история подтверждает выступление за другой клуб в том же турнире и сезоне, бот не присваивает общий сезонный показатель одному клубу. Сезон требует раздельного подтверждения. Защита не вызывает дополнительные запросы протоколов. Разделение Грифо в черновике — отдельно проверенная правка, автоматического разделения этим изменением не добавлено.

Файлы исправленных статей лежат в `../latest/articles/`; архив `../latest/four-articles.zip` пересобран. Исходный архив доказательств не изменён. Разницу показывают `Грифо-correction.diff` и `Крамарич-correction.diff`.

## Что остаётся неподтверждённым

- Грифо: отдельная строка «Хоффенхайм II» 2013/14 (8/4) не включена: ранее разрешение команды/лиги не прошло проверку. Остальные старые выступления за резерв по сезонам также не закрыты. В пакете 16 неизвестных пар категорий/сезонов.
- Крамарич: итог сборной в API 119/36, реконструкция матчей 116/35. Старые данные сборной сохранены; новая СбМатчи не создана. В клубном пакете 14 неизвестных пар категорий/сезонов.
- Центнер: сезонные пропущенные голы за резерв «Майнца» и «Хольштайн» не подтверждены. В карточке сохранены старые итоги −39 и −28; нули в сезонной таблице не доказывают отсутствие пропущенных голов. В пакете 10 неизвестных пар категорий/сезонов. Для трёх старых ссылок на сезоны подходящие статьи не найдены в сохранённой проверке названий.
- Шик: 56/26 сборной подтверждены. API не покрывает 19 категорий старых клубных сезонов; прежние показатели сохранены.

По текущей инструкции неизвестные новые клубные ячейки отображаются нулями. Это правило отображения, а не подтверждение фактического нуля. Поэтому отсутствие ошибок в проверенных значениях не означает полную точность всей карьеры.
