# Проверка основного кода на исходных четырёх статьях

13 октября 2026 года. Запущен `prepare_player` на исходных `before.wiki`, без подготовленного удаления клубных таблиц, дополнения матчей федерации или исправления карточек. Статистика взята из сохранённых ответов Sofascore. Запросов к футбольному API и правок Википедии — 0. Для недостающих идентичностей использовались чтения Wikimedia; часть источников недоступна.

Результат полного последнего прогона:

|---|---|---|---|
| Грифо | Фрайбург 227/60, 11.10.2026 | 227/60 | Обновлена автоматически |
| Крамарич | Хоффенхайм 293/130, 14.02.2026 | 310/135 | Обновление заблокировано |

| Шик | Байер 149/80, 16.05.2026 | 154/85 | В последнем полном запуске заблокировано недоступным источником идентичности старого клуба |

У Крамарича не находятся единственные сезоны-якоря при добавлении строк. Затем нормализация ссылок на сезоны получает `old_value_mismatch` после изменения структуры таблицы; вся группа `sofascore-reconciliation`, включая карточку, отклоняется. Сборная остаётся 112/36: неполный подробный список API по-прежнему не обновляет карточку независимо от СбМатчи.

У Шика предыдущие запуски с доступными идентичностями обновляли клубную карточку до 154/85 и 10.10.2026. Последний полный запуск показал зависимость обновления карточки от проверок дополнительной таблицы: `wiki_source_unavailable` блокирует всю группу. Это ограничение прогона и нежелательная связь основных и дополнительных действий, а не доказательство неверности 154/85.

У Грифо основной код разделяет также переходный сезон 2019/20: Фрайбург 26/4, Хоффенхайм 1/0; кубок — по одному матчу каждому клубу. Поэтому в готовом черновике из `2026-10-12/latest` число 228 в текущем периоде Фрайбурга завышено на один. Прежняя проверка готовых черновиков проверяла разделение только 2018/19 и пропустила это расхождение. Черновик и прежний отчёт не заменяют этот автоматический прогон.

Повторный запуск всех завершённых планов не меняет их результат. Это не означает успех: отклонённый план также может повторяться без изменений. Исходные сноски сохранены, новых арифметических ошибок не обнаружено.

`report.json` содержит статусы и причины отказов, `*-automatic.wiki` и `*-automatic.diff` — фактический вывод основного кода. Эти файлы служат проверке и не являются готовыми к публикации статьями.

Следующие исправления: не связывать обновление карточки с необязательной подробной статистикой; исправить последовательное планирование нормализации, добавления сезонов и сезонных ссылок; дать сборной в карточке отдельный путь обновления по проверенному агрегату.

Повторить без сети: `python -X utf8 tools/replay_four_infoboxes.py`. Обновить только идентичности Wikimedia: та же команда с `--refresh-wiki`. Футбольный провайдер остаётся отключён в обоих режимах. Код возврата 1 означает, что хотя бы одна клубная карточка не достигла ожидаемого результата.
