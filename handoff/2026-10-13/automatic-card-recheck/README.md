# Автоматическое обновление четырёх исходных статей

13 октября 2026 года. Основной prepare_player запущен на исходных before.wiki, без ручного исправления карточек, удаления таблиц или добавления матчей федерации. Использованы сохранённые ответы Sofascore и идентичности Wikimedia. Новых запросов к футбольному API и правок Википедии — 0.

|---|---|---|---|---|
| Грифо | Фрайбург 227/60 | 11.10.2026 | 9/4 | 26.03.2023 |
| Крамарич | Хоффенхайм 310/135 | 10.10.2026 | 119/36 | 02.07.2026 |
| Центнер | Майнц 210/−314 | 12.09.2026 | Молодёжная строка сохранена | Не добавлена |
| Шик | Байер 154/85 | 10.10.2026 | 56/26 | 25.06.2026 |

Все четыре клубные карточки и даты совпали с проверяемыми сохранёнными данными. Проверки основной сборной прошли для Грифо, Крамарича и Шика. Повторный запуск не меняет результат; исходные сноски сохранены; новых арифметических ошибок не обнаружено.

Обновление карточки отделено от КлСтат и СбМатчи. Числа и дата соответствующей карточки проверяются совместно: ошибка даты не оставляет обновлённые числа со старой датой. Добавление сезонов использует нужный блок клуба, учитывая аренду; флаги и сезонные ссылки планируются после изменения таблицы.

Дополнительно исправлены тире в сезонных итогах. Сезонный режим теперь использует сохранённую полную историю для доказательства нулевого участия: это не замена всех пропусков на ноль. У Грифо, например, Фрайбург 2016/17 теперь имеет 32 матча / 9 голов, 2021/22 — 40/13, 2024/25 — 37/10. За 2015/16 и в части более старых сезонов подтверждения по-прежнему недостаточно: их полный итог остаётся неизвестным. Текущий сезон тоже не закрывается таким доказательством. Явные известные итоги сезонов используются для итога клуба при неполной разбивке; устаревшие итоги не сохраняются после изменения их составляющих.

Сравнение с предыдущим автоматическим выводом восстановило у Грифо восемь полных сезонных итогов. Список прежних и новых значений — `restored-totals.json`, он также включён в архив. Клубные карточки при этом не изменились. Это исправление не превращает неполный итог всей карьеры в полный.

У Крамарича основной код обновил сборную в карточке по агрегату API до 119/36. Подробный список содержит только 116 матчей / 35 голов: бот не добавляет недостающие встречи и не выдаёт этот список за полный. У Шика сохранённых идентичностей старых клубов недостаточно для создания подробной клубной таблицы; её изменение отклонено, а карточка обновлена. Это не проверка всей биографии или всех старых чисел статьи.

У Грифо переходный сезон 2019/20 разделён: Фрайбург 26/4, Хоффенхайм 1/0. Число 228 для текущего периода Фрайбурга в прежнем ручном черновике 2026-10-12/latest было завышено на один. Для нового просмотра используйте файлы из этой папки.

*-automatic.wiki — фактический текст после бота; *-automatic.diff — изменения; *-package.json и report.json — операции, результаты и причины пропусков. automatic-four.zip содержит четыре автоматических текста и этот файл. Это черновики для просмотра, не опубликованные статьи. Ревизии пакетов относятся к сохранённым оригиналам: перед публикацией на текущей странице нужна повторная проверка.

Повторить без сети:

```powershell
python -X utf8 tools/replay_four_infoboxes.py
```

Код 0 означает совпадение проверяемых клубных чисел и дат, чисел основных сборных, сохранность сносок, отсутствие новых арифметических ошибок и успешный повторный запуск. Код 1 означает отказ хотя бы одной из этих проверок. --refresh-wiki разрешает только ограниченное чтение Wikimedia для идентичностей; футбольный провайдер остаётся отключён.
