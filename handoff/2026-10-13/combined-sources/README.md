# SofaScore6 + OmkarCloud

Подключены к существующему циклу `--provider sofascore`. SofaScore6 включается
через защищённую переменную `SOFASCORE6_API_KEY`; старые ключи OmkarCloud
остаются в прежней конфигурации. Секрет добавлен на Toolforge, в репозитории его нет.

Профиль, список сезонов, национальные итоги и отдельные сезонные показатели
`overall` сначала читаются через SofaScore6. Ошибка или неполный ответ переводит
этот запрос к OmkarCloud. Матчи и протоколы остаются на проверенных методах
OmkarCloud: новый метод не доказывает команду выступления игрока. Карьерная
разбивка не используется как готовая статистика из-за найденного расхождения.
Таким образом, подключение не обещает экономии общего карьерного запроса:
сезонные показатели пока запрашиваются отдельно.

Общий кеш нормализованных данных; раздельные счётчики, сроки сброса, паузы и
состояния ключей. Неизвестная квота разрешает один пробный запрос, не весь лимит.
Неполные или противоречивые данные не заменяются придуманными нулями.

## Сервер

Код размещён отдельно в
`/data/project/brackelbot/reports/combined-sofascore-20261013/code`.
Вход: `/data/project/brackelbot/operator-combined.sh`.
Он сохраняет старую рабочую директорию и настройки хранилища. Старый checkout
`brackelbot` с многочисленными локальными изменениями не перезаписывался.
Прежний `toolforge/operator.sh` продолжает указывать на прежний checkout;
для новых заданий со связкой нужно использовать `operator-combined.sh`.

Пример чтения сохранённого учёта без запросов провайдеру:

```bash
toolforge jobs run bb-combined-quotas --image python3.13 --command './operator-combined.sh --provider sofascore api-quotas' --wait
```

Подробности: `docs/SOFASCORE.md`. Ограничение бесплатного плана SofaScore6 в
адаптере — 500 запросов; платный план нельзя включать одной сменой заголовка.
