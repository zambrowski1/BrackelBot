# Каталог сезонов BrackelBot — 12 октября 2026

Готовый каталог: **2077 статей сезонов 2010–2026**, 253 группы лиг/названий. Из них 212 связаны с объектами Wikidata, 41 основана на названиях и категориях Википедии. Это число групп, а не доказанное число отдельных соревнований.

Пройдено 354 категории с обработкой всех продолжений ответов. Запросы Wikidata дополнены поиском сезонов без требования к типу сезона. Сохранены 341 подтверждённое перенаправление на названия лиг. У связанных лиг найдено 115 значений свойства P17; это географические объекты из Wikidata, включая территории и исторические значения.

Каталог подключён к поиску ссылок в КлСтат. Перед правкой бот проверяет существование страницы. Разные дивизионы, мужские и женские соревнования, календарные и переходные сезоны не объединяются. При нескольких подходящих статьях произвольная ссылка не выбирается. Страницы составов, кубки и прочие неподходящие турниры исключены.

Полный прогон: **1597 passed**, 229,47 секунды. После добавления перенаправлений: **28 passed** и успешная проверка всех 2077 записей по сохранённым источникам. Четыре прежних черновика прошли повторную проверку. Сбор воспроизведён без сети; каталог проверен в установочном пакете.

Футбольный API: **0 запросов**. Записи в Википедию: **0**.

## Файлы

- `catalogue.csv` — принятые статьи сезонов.
- `coverage.csv` — найденные статьи по лигам и годам. Пусто означает «не найдено этим поиском».
- `review.json` — случаи, которые не используются автоматически, и исключённые страницы.
- `validation.txt`, `tests.txt`, `catalogue-tests.txt` — результаты проверок.
- `discovery.json`, `responses/`, снимки Wikidata и перенаправлений — источники для воспроизведения.
- `manifest.json` — SHA-256 файлов архива.
- `season-catalogue.zip` — каталог, источники, код сбора и инструкция.

## Границы результата

Полностью обойдены найденные корневые категории. Это не гарантирует нахождения каждой статьи русской Википедии: отсутствие категорий, связей Wikidata или нестандартное название может помешать поиску. В `review.json` остаются 162 случаев без подтверждения типа лиги и 115 случаев вне диапазона либо с нестандартным названием; среди них есть другие соревнования, а не только лиги. Их не следует добавлять в каталог только по сходству названий.

Обновление каталога описано в `docs/SEASON_CATALOGUE.md`. Сетевые команды запускаются последовательно; кеш позволяет продолжить прерванный сбор.
