# СбМатчи

Один вызов шаблона содержит заголовок и все матчи одной сборной. Строки не
требуют подшаблонов. Lua-модуль строит таблицу с прежними шестью колонками
и автоматически вычисляет номера, игры, голы, победы, ничьи и поражения.

Файлы подготовлены для установки; в Википедии пока не опубликованы:

| Страница Википедии | Файл |
|---|---|
| `Модуль:СбМатчи` | `Модуль.lua` |
| `Шаблон:СбМатчи` | `Шаблон.wiki` |
| `Шаблон:СбМатчи/doc` | `Документация-обновлённая.wiki` |

`Браккельман.wiki` — преобразование предоставленной пользователем таблицы,
а не независимая проверка данных DFB. Ссылки на источники из исходной статьи
нужно сохранить в `источникN` или `источники`.

Для первого просмотра можно использовать `Модуль:СбМатчи/Песочница` и
`Участник:Zambrowski/СбМатчи`: в строке `#invoke` замените имя модуля на
`СбМатчи/Песочница`, а в примере имя шаблона на `Участник:Zambrowski/СбМатчи`.
Публикация шаблона не означает согласования массовой замены таблиц.

Проверка локально:

```bash
python -m pip install -r requirements-lua-tests.txt
python -m pytest tests/test_sbmatches.py -q
```

Тесты исполняют настоящий модуль в Lua 5.1 с заглушками аргументов,
`mw.html` и раскрытия существующих шаблонов. Разметка и арифметика проверяются
локально; оформление флагов, ссылок, сносок и работа кнопки сворачивания
требуют дополнительного предпросмотра в Википедии.

Бот пока не изменяет `СбМатчи`: поддержка чтения и точечных исправлений этих
параметров — отдельный следующий шаг. Создание файлов не включает сборные
в текущий цикл Sofascore.

Реализация использует [Scribunto](https://www.mediawiki.org/wiki/Extension:Scribunto/Lua_reference_manual)
и не требует дополнительных сторонних модулей Википедии.

Короткий вариант: `Браккельман-кратко.wiki`. Формат `матчN=дата ;; соперник ;; счёт ;; голы [;; соревнование]`; общее `соревнование` позволяет избежать повторов. Источник и серия пенальти остаются отдельными параметрами. Подробный формат сохраняется.
